How to add this to Gmail

  1. Make sure your site is live with assets/img/portfolio-badge.gif uploaded. The image is loaded from there.
  2. Click inside the dashed box below and press Ctrl + A, then Ctrl + C.
  3. In Gmail: ⚙️ Settings → See all settings → General → Signature → Create new, then paste with Ctrl + V.
  4. Click the image in the editor once and choose Small if it looks too big. Scroll down and click Save Changes.
